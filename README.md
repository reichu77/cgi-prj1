# CGI 2026/27 - Projeto 1: Diagramas de Voronoi

Enunciado: https://gitlab.com/CGI-Code/cgi-26-27/-/blob/main/doc/prjs/project1-en.md

## Como correr

Abrir `src/prjs/prj1/index.html` com o Live Server do VS Code (os shaders são
carregados por `fetch`, por isso é preciso um servidor; abrir o ficheiro
diretamente não funciona).

## Estrutura

- `src/prjs/prj1/` - o projeto
- `src/libs/` - `utils.js` e `MV.js`, copiadas do repositório da cadeira
